# TaskFlow AI

**A modern task and project management application built with Flutter and Dart.**

TaskFlow AI helps users organise tasks, manage projects, monitor progress, and improve productivity through a responsive interface.

## Features

- Create, edit, complete, and delete tasks
- Create and manage projects
- Organise tasks by project
- Advanced search and filtering
- Sort by priority, due date, and title
- Track task and project completion
- Persistent local storage
- Responsive Material Design 3 interface

## Tech Stack

- **Flutter & Dart** — Application development
- **Riverpod** — Reactive state management
- **SharedPreferences** — Local data storage
- **Material Design 3** — UI components
- **Modular architecture** — Code organisation

## Getting Started

Clone the repository:

```bash
git clone https://github.com/MuhammadMohsin442/taskflow_ai.git
cd taskflow_ai
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run -d chrome
```
